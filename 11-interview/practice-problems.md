# Practice Problems

Har problem ko alag file mein khud solve karo (`solutions/` folder banao). Pehle brute force, phir optimize.

## Easy
1. FizzBuzz (1-100)
2. String reverse aur palindrome check
3. Array ka max/min (loop se, `Math.max` ke bina)
4. Vowels count karo
5. Duplicate hatao (`Set` ke saath aur bina)
6. Factorial (loop + recursion)
7. Prime number check
8. Fibonacci (loop, recursion, memoized)
9. Do arrays ka intersection
10. Title Case: `"hello world"` -> `"Hello World"`

## Medium
1. Two Sum (hashmap se O(n))
2. Anagram check aur anagram groups
3. Balanced brackets
4. Array chunk: `chunk([1,2,3,4,5], 2)`
5. Flatten nested array/object
6. Word frequency counter
7. Longest word / longest common prefix
8. Rotate array by k
9. Group by property (`reduce`)
10. Debounce aur throttle
11. Deep clone aur deep equal
12. Curry aur compose

## Hard
1. `Promise.all`, `race`, `allSettled` polyfills
2. Concurrency limit wala async runner
3. LRU cache (`Map` se)
4. EventEmitter class
5. Pub/Sub system
6. Retry with exponential backoff
7. Memoize with custom resolver
8. Observable / reactive state (Proxy se)
9. Binary search, merge sort, quick sort
10. Linked list, stack, queue khud implement karo

## Mini Projects (DOM)
Calculator, Counter, Quiz app, Weather app (fetch), Movie search (debounce), Expense tracker, Typing speed test, Kanban board (drag and drop), Infinite scroll (`IntersectionObserver`).

## Tips
- Pehle problem ko chhote examples par haath se solve karo.
- Edge cases socho: empty input, negative, duplicates, bohot bada input.
- Time aur space complexity batana seekho (Big O).
- LeetCode, Codewars, Frontend Mentor par roz 1-2 problems.
