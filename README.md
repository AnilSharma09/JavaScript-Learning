# JavaScript Learning Repo

JavaScript zero se advanced tak. Har folder mein runnable `.js` files hain jisme concept + examples + **EXERCISE** (khud solve karne ke liye) diye hain.

## Setup
Node.js 20+ chahiye.
```bash
node -v
node 01-basics/variables-types.js   # koi bhi file chalao
node run-all.js                     # saari example files ek saath
```
Browser wale folders (`09-dom`, `10-projects`) ko VS Code ke **Live Server** se kholo.

## Roadmap

| Folder | Topics | Time |
|---|---|---|
| `01-basics` | Variables, types, operators, conditions, loops | 3-4 din |
| `02-functions` | Functions, arrow, callbacks, HOF, recursion | 3 din |
| `03-arrays-objects` | Array methods, destructuring, spread, Set/Map | 1 hafta |
| `04-strings-math-date` | Strings, Math, Date, Intl, regex | 3-4 din |
| `05-deep-concepts` | Scope, hoisting, closures, `this`, bind | 1 hafta |
| `06-oop` | Prototype, classes, inheritance | 4-5 din |
| `07-async` | Callbacks, Promises, async/await, event loop | 1-2 hafte |
| `08-modern-js` | Modules, generators, Proxy, iterators | 4-5 din |
| `09-dom` | DOM, events, delegation, storage, fetch | 1-2 hafte |
| `10-projects` | To-do app (DOM + localStorage) | saath-saath |
| `11-interview` | Polyfills, output questions, coding problems | ongoing |

Total lagbhag 10-12 hafte, roz 2-3 ghante.

## Kaise padhein
1. File kholo, code padho, phir **chalao** aur output dekho.
2. Output predict karo chalane se pehle.
3. File ke end mein **EXERCISE** khud solve karo (alag file mein).
4. Har folder ke baad GitHub par commit karo.

## Practice Projects
Calculator, Counter, To-do app (included), Quiz app, Weather app (fetch), Movie search (debounce), Expense tracker, Typing speed test, Kanban board.

## Interview Topics
Closures, hoisting, `this`, prototype chain, event loop, `==` vs `===`, `var/let/const`, Promise vs async/await, debounce/throttle, event delegation, deep clone, polyfills (`map`, `bind`, `Promise.all`).
